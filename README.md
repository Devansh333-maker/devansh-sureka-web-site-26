# Devansh Sureka — personal site

My portfolio, built as a small world you can walk around: a 3D island with six places, one for each
kind of work (civil engineering, AI and product, NSS, roll ball, design and writing), plus a Work page
that lists everything in one place.

Built with Next.js 15, React 19, three.js / React Three Fiber and plain CSS.

## Run it

```bash
npm install
npm run dev        # http://localhost:9002
npm run build      # production build
npm run lint
npm run typecheck
```

`NEXT_PUBLIC_SITE_URL` sets the site's own address (used for share previews and the sitemap).
